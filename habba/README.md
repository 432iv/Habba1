# هبّـة | HABBA — دليل المشروع

متجر عطور إلكتروني **متعدد العلامات** بواجهة عربية RTL، مبني على فلسفة التصميم في الصورة المرجعية (بطاقات منتجات مستديرة، مساحات بيضاء سخية، شريط تنقل عائم، أزرار دائرية) لكن مُعاد تصميمه بالكامل ليكون ملائماً لمتجر عطور فاخر.

> **هبّة هو المتجر.** لافيرن، إبراق، جامبول… هي علامات تُباع داخله، وليست ملكاً لهبّة. هذه الفكرة ظاهرة في الواجهة: شعار المتجر ثابت في الرأس، اسم العلامة يظهر كتصنيف فرعي على كل منتج، وصفحات العلامات تحتوي تنبيهاً صريحاً بذلك.

---

## 1) التشغيل

| الطريقة | الخطوات |
|---|---|
| **سيرفر محلي (موصى به)** | من داخل مجلد المشروع: `python3 -m http.server 8080` ثم افتح `http://localhost:8080` |
| **بدون سيرفر** | افتح `HABBA-standalone.html` مباشرة في أي متصفح — كل شيء مضمّن في ملف واحد (خطوط + صور) ويعمل دون إنترنت |
| **بناء الملف المستقل** | `python3 build.py` — يعيد توليد `HABBA-standalone.html` بعد أي تعديل |

لا توجد أي تبعيات أو أدوات بناء (لا npm، لا bundler). HTML + CSS + JavaScript خام.

## 3) ما يجب تعديله قبل الإطلاق

### أ) رقم واتساب — الأهم
في `js/config.js`:

```js
whatsappNumber: "",   // ← ضع الرقم هنا بالصيغة الدولية بدون + أو مسافات
                      // مثال: "218911234567"
```

- إذا تُرك فارغاً: يعمل الطلب، وتظهر رسالة تنبيه تقول إن الرقم لم يُعد، مع **نسخة من رسالة الطلب وزر نسخ** كي لا تضيع.
- عند تعبئته: يُفتح واتساب تلقائياً برسالة الطلب جاهزة (`https://wa.me/218…?text=…`).

### ب) بيانات المتجر
نفس الملف: `deliveryFee`، `freeDeliveryThreshold`، `storeAddress`، `email`، `instagram`، أسماء المتجر والعملة.

### ج) المنتجات والعلامات
كلها في `js/data.js` — أضف منتجاً أو علامة أو حجماً أو فئة دون لمس الواجهة.
**الصور الحالية تجريبية** (bottles مولّدة بلا نصوص) — استبدلها بصور المنتجات الحقيقية بنفس المسارات أو بتحديث حقل `image`.

### د) العطور الرجالية
- الفئة `men` موجودة في `data.js` لكن `enabled: false` فتظهر كـ «قريباً» في شريط الفئات.
- لإطلاقها: انقل `enabled` إلى `true` وأضف منتجات فيها `gender: "men"`.
- بنية البيانات، الفلاتر، وصفحات العلامات **لا تفترض** أن كل شيء نسائي — التصنيف مجرد حقل.

## 4) الصفحات والمسارات

| المسار | الصفحة |
|---|---|
| `#/` | الرئيسية: Hero، فئات، علامات، شبكة منتجات |
| `#/product/:id` | تفاصيل العطر: معرض، أحجام، هرم نفحات، مواصفات، شريط شراء ثابت |
| `#/brand/:id` | مجموعة العلامة: مقدمة، تصفية بالعائلة العطرية، ترتيب، شبكة |

| `#/checkout` | إتمام الطلب: بيانات، استلام/توصيل، مراجعة، إرسال واتساب |

## 5) نظام التصميم

**الألوان** (كما في الموجز، مع تعديل بسيط للتباين):

| الرمز | القيمة | الاستخدام |
|---|---|---|
| `--ivory` | `#F8F6F1` | خلفية الصفحة الأساسية |
| `--sand` / `--sand-50` | `#E9E0D2` / `#F2EBE0` | أسطح ناعمة، ملخصات |
| `--espresso` | `#29251F` | النص الأساسي، الأزرار، الفئة النشطة |
| `--gold` | `#B69A63` | لمسات فقط (نقاط، أيقونات صغيرة) |
| `--taupe` | `#8C8172` | عناصر ثانوية/حدود — **ليس لنص قراءة** |
| `--ink-2` `--ink-3` | `#6E6558` `#776E60` | نص ثانوي بتباين ≥ 4.5:1 |

> ملاحظة: `Soft Taupe #A69B8D` الأصلي يعطي تباين 2.5:1 على الخلفية العاجية — أقل من معيار WCAG AA. لذلك استُخدم للأيقونات والحدود فقط، وأُضيف `#776E60` للنصوص الثانوية.

**الخطوط**: IBM Plex Sans Arabic (300–700) للعربية، Manrope (400–700) للاتينية، مستضافة محلياً — لا طلبات لجوجل.

**الأنماط**: نصف قطر 32/24/18px، ظلال ناعمة جداً (`0 22px 44px -34px`)، حركة 200–420ms بمنحنى `cubic-bezier(.22,.7,.24,1)`.

## 7) سلوك الطلب عبر واتساب (بدون حساب)

1. السلة تُحفظ في المتصفح (`habba.cart.v1`) — تكمل حتى لو أُغلق الموقع.
2. عند «تأكيد الطلب»: تحقّق من الاسم (≥3 أحرف)، الهاتف (≥9 أرقام)، والعنوان إذا اختير التوصيل.
3. تُبنى رسالة عربية منسّقة تضم: الاسم، الهاتف، طريقة الاستلام، العنوان، المنتجات (اسم + علامة + حجم + كمية × سعر)، المجموع الفرعي، رسوم التوصيل، الإجمالي.
4. تُفتح `wa.me` في نافذة جديدة **قبل** تفريغ السلة، ثم تُفرَّغ السلة وتظهر نافذة تأكيد فيها الرسالة وزر نسخ احتياطي.
5. التوصيل مجاني فوق `freeDeliveryThreshold`، ولا تُحتسب رسوم عند الاستلام من المحل.

## 8) الالتزام بالموجز

✅ RTL كامل · Mobile-first (390px) · تابلت · ديسكتوب (شبكة 4 أعمدة + تنقل مدمج في الرأس)
✅ شريط تنقل عائم كبسولة على الموبايل، يختفي في صفحة المنتج لصالح شريط الشراء الثابت
✅ مفضلة بتفاعل متحرك + حفظ محلي، بحث فوري مع حالات تحميل/فراغ/لا نتائج
✅ علامات مستقلة عن الفئات (نظامان منفصلان للتصفح)
✅ لا أرقام هاتف أو شعارات أو مواصفات رسمية مُختلقة — البيانات موسومة كتجريبية
✅ احترام `prefers-reduced-motion`، Skip link، تسميات ARIA، أهداف لمس ≥ 42px، تباين مطابق
✅ بلا أي مكتبات خارجية أو خطوط من CDN

## 9) ملاحظات تقنية

- الراوتر يعتمد `hash` حتى يعمل من أي استضافة ثابتة أو من ملف محلي مباشرة.
- الصور `loading="lazy"` مع `width/height` لتقليل انزياح التصميم.
- `--safe-area-inset-bottom` مدعومة في شريط التنقل وشريط الشراء (iPhone).
- ملف `HABBA-standalone.html` حجمه ~1.2MB لأن الخطوط والصور مضمّنة base64 — للاستخدام السريع أو المشاركة، وليس للنشر على استضافة (استخدم `index.html` مع الأصول).

### تشغيل محلي
```bash
cd habba
python3 -m http.server 8080 --bind 0.0.0.0
# المتجر :  http://localhost:8080/
# اللوحة :  http://localhost:8080/admin/
```

### تشغيل كل الاختبارات
```bash
./run_all_tests.sh          # الأرقام تُقرأ من الاختبارات نفسها، لا تُكتب يدوياً
```

> ⚠️ الأرقام أعلاه هي **آخر نتيجة مقيسة فعالً**. لا تُحدَّث يدوياً — شغّل `./run_all_tests.sh` واقرأ الجدول.

> ⚠️ لم يُنشأ أي مشروع Supabase ولم يُنشر شيء. المتجر بملفاته الستة **لم يتغيّر بايتاً واحداً** (`md5sum -c storefront.sha256`).
